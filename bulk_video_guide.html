▶ Bulk Review Video Upload Guide

ISKCON Book Store — Admin Instructions for uploading multiple book review videos

Overview — How It Works

Instead of uploading and linking videos one by one, you can:

  1. Collect all review videos from devotees
  2. Rename all video files properly on your computer
  3. Upload all videos to YouTube at once (all together simultaneously)
  4. Note down each YouTube link next to the book name
  5. Go to Admin → Bulk Video Update page → paste all links → Save All
✓ Time saving: Instead of editing 20 books one by one, you paste all YouTube links on one single page and click Save All — done in 2 minutes.

Part 1 — Collect Videos from Devotees

1
Ask devotees to record 30-second review videos Each devotee records a video about one specific book — what it is about, how it helped them, why others should read it.
2
Tell devotees to record HORIZONTALLY Phone must be turned sideways (landscape) when recording — not upright.
❌ WRONG — Phone upright ✅ CORRECT — Phone sideways ┌───┐ ┌──────────────┐ │ │ │ │ │ │ │ │ │ │ └──────────────┘ └───┘ Portrait mode Landscape mode
3
Collect all videos via WhatsApp Devotees send video files to admin via WhatsApp. Save all videos to one folder on your computer.

Part 2 — Rename Video Files on Your Computer

Why rename? YouTube uses the filename as the video title automatically. If you rename files before uploading, you save time filling in titles one by one.
1
Open the folder where you saved all videos You will see files named like WhatsApp_Video_2026... etc.
2
Right-click each file → Rename → type the book name Follow this exact format:
BookName_Review.mp4
Examples:
Bhagavad_Gita_Review.mp4 Srimad_Bhagavatam_Review.mp4 Nectar_of_Devotion_Review.mp4 Krishna_Book_Review.mp4 Chaitanya_Charitamrita_Review.mp4
Rule: Use underscores ( _ ) between words. No spaces. End with _Review.mp4

Part 3 — Upload All Videos to YouTube at Once

1
Open YouTube Studio Go to youtube.com → sign in → click + Create (top right) → click Upload video
2
Select ALL video files together Click Select files → open the folder with your renamed videos → press Ctrl + A to select all files → click Open.

All videos will start uploading simultaneously in the background.
3
Fill details for each video one by one YouTube will show each video one at a time. For each:
  • Title will be auto-filled from the filename ✓
  • Click Next → Next → Next
  • On Visibility screen — select Unlisted
  • Click Save
Then YouTube moves to the next video automatically.
4
Answer "Is this made for kids?" — always select No This question appears on the Details screen for each video. Always select No, it's not made for kids.

Part 4 — Copy Each YouTube Link

Important: After saving each video, immediately note down the YouTube link and which book it belongs to. Keep a list like this:
Book Name YouTube Link
Bhagavad Gita https://youtube.com/shorts/ABC111...
Srimad Bhagavatam https://youtube.com/shorts/ABC222...
Nectar of Devotion https://youtube.com/shorts/ABC333...
1
After saving each video on YouTube YouTube shows a "Video published" popup with the video link at the bottom.
2
Click the copy icon next to the link The link is copied to your clipboard.
3
Paste it in a Notepad file or WhatsApp note Write the book name next to each link so you don't confuse them. Example:
Bhagavad Gita - https://youtube.com/shorts/TqA7LBDdeik Srimad Bhagavatam - https://youtube.com/shorts/XyZ123abc Nectar of Devotion - https://youtube.com/shorts/MnP456def
4
To find links later from YouTube Studio Go to studio.youtube.com → click Content → all your uploaded videos appear → click on any video → the link is shown on the right side.

Part 5 — Add All Links in Admin Panel (Bulk Update)

1
Open the Admin Panel Go to your store website → add /admin/login at the end → enter username and password.
2
Click "Books" in the left menu
3
Click the red "Bulk Video Update" button It is at the top right of the Books page next to the Add Book button.
4
You will see a table with all books Each book has a text field on the right side for the YouTube link. The Status column shows:
  • Video set — YouTube link already added
  • No video — no video yet, paste link here
5
Paste each YouTube link next to the correct book Use your Notepad list from Part 4. Find the book → paste the YouTube link in the field next to it. Leave blank for books that have no video yet.
6
Click "Save All" button at the bottom All links are saved at once. Done!
7
Verify on the store website Open any book page → scroll down → "What Devotees Say" section → video should play.

Important Rules

  • Always record video horizontally (phone sideways) — not upright
  • Always set YouTube visibility to Unlisted — never Public or Private
  • Always write down the YouTube link immediately after saving — don't rely on memory
  • One video per book — if you paste a new link, it replaces the old one
  • Do not use the "Upload Video File" button in Edit Book — those files are deleted when server restarts
  • Any YouTube link format works — Shorts, watch URL, youtu.be — all are accepted
